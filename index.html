📋

Two tiers of BSN.Cloud

BSN.Control (free) — player setup, management, monitoring.  |  BSN.Content (subscription) — everything in Control + cloud content hosting, dynamic playlists, scheduling, and publishing. You need BSN.Content to host and publish content remotely.

💡

Publishing Methods — Know the difference

Standalone — USB/SD card only, no network. LFN (Local File Networking) — local server. SFN (Simple File Networking) — shared folder on LAN. BSN.Cloud — full cloud management. Most UberDisplays installs use BSN.Cloud.

🗺️ BrightSign Ecosystem Overview

Understanding how the pieces fit together before you start saves hours of frustration.

BrightSign Player

The hardware media player that runs your content. Connects to your display via HDMI. Stores content on internal storage or SD/USB. Managed remotely via BSN.Cloud or locally via BrightAuthor:connected.

BrightAuthor:connected

Free Windows/Mac desktop app — the primary tool for creating presentations, managing players, and publishing content. Connects to BSN.Cloud for remote management. This is where you design everything.

BSN.Cloud

BrightSign's cloud platform. BSN.Control (free) handles player setup and monitoring. BSN.Content (paid) adds cloud content hosting, dynamic playlists, and remote publishing. Accessed via browser at bsn.cloud or through BrightAuthor:connected.

Presentation

A project file you build in BrightAuthor:connected. Contains zones, playlists, schedules, and settings. Published to a player or group of players. Think of it as the "show" that runs on screen.

Groups

Logical groupings of players in BSN.Cloud. Assign a presentation and schedule to a group — all players in that group play the same content. Essential for multi-location deployments.

Dynamic Playlist

A cloud-hosted playlist that multiple presentations can reference. Update the dynamic playlist once — every presentation using it picks up the change automatically. Requires BSN.Content subscription.

☁️ BSN.Cloud — Account & Network Setup

Creating Your Account & First Network

  1. Open BrightAuthor:connected → click Connect on the login screen → select Sign in as a new user
  2. Enter your email and create a password → verify your email address → return to BrightAuthor:connected and log in
  3. Give your BSN.Cloud network a name (e.g., "UberDisplays Main") → agree to terms → click Create
  4. Your new network is a BSN.Control network by default (free tier)
  5. To enable BSN.Content: go to the Admin tab → select BSN Content Trial to start a subscription — or see BSN.Cloud pricing
  6. To create additional networks: Admin tab → New Network → enter a unique name → click Create. You'll receive a setup email.
🎥
Official account setup video: vimeo.com/349557791 — walks through signing up and first network creation.

BSN.Cloud Portal — Key Sections

Network Tab

View and manage all players on your network. See online/offline status, player model, firmware version, IP address. Add or remove players. Organize into Groups.

Content Tab

Upload and manage media files (video, images, audio). Create dynamic playlists, live data feeds, and live media feeds. Requires BSN.Content subscription.

Presentation Tab

View all presentations on your network. See which players or groups each presentation is published to. Publish, unpublish, or reassign presentations.

Schedule Tab

Set time-based schedules for content playback. Assign different presentations to different time slots or days of the week per player or group.

Admin Tab

Manage user accounts and permissions, create new networks, manage subscriptions, view storage usage, and set network-wide settings.

Groups

Organize players into groups (by location, display type, or client). Publish one presentation to the whole group. All players in the group automatically receive the same content.

🖥️ BrightSign Players — Setup & Registration

Adding a New Player to BSN.Cloud

  1. Power on the player and connect it to your network via Ethernet (recommended for initial setup). Connect HDMI to your display.
  2. The player will show a setup screen on first boot with a serial number and setup code. Note these down.
  3. In BrightAuthor:connected → go to the Network tab → click Add Player
  4. Enter the player's serial number or use the auto-detect feature if it's on the same LAN
  5. Follow the setup wizard — the player downloads a setup file from BSN.Cloud and registers itself to your network
  6. Once registered, the player appears in your Network tab — assign it to a Group
  7. Publish a presentation to the group or directly to the player — content downloads and playback begins

🎨 Building Presentations in BrightAuthor:connected

Creating a New Presentation

  1. Open BrightAuthor:connected → go to Presentation tab → click New Presentation
  2. Select your Target Player model — this is critical, it sets what's available
  3. Select Output Resolution — match this to your display (e.g., 1920×1080 for 1080p, 3840×2160 for 4K)
  4. Select a Template: Single Zone (one fullscreen item at a time), Playlist, Multi-Zone, HTML, or Video Stream
  5. Set Screen Orientation: Landscape, Portrait-Bottom Left, or Portrait-Bottom Right
  6. Click Start — you enter the Presentation Builder
  7. In the Layout tab: position and resize zones on your canvas
  8. In the Content tab: drag media from the library into each zone's playlist
  9. Set image display duration using the stopwatch icon on each image. Videos play their full length automatically.
  10. Click Save → then Publish to push to your player(s)

Simple vs Advanced Zones

Simple Zone

Loops media endlessly in order. No interactivity or conditional logic. Fast and easy to set up. All you need for most digital signage — images and videos that loop continuously.

Use for: Menu boards, lobby displays, retail signage

Advanced Zone

Supports events and transitions — content changes based on triggers (GPIO button press, touchscreen input, timer, UDP command, etc.). Complex presentations with interactivity. Once you add events, you can't revert to Simple.

Use for: Interactive kiosks, touch displays, event-triggered content

Content Storage Modes

BSN Content Mode ☁️

Media stored on BSN.Cloud. Changes and updates happen remotely. Required for dynamic playlists and multi-player publishing via cloud. Requires BSN.Content subscription.

Local Mode 💻

Media stored on your local machine. Presentation published via USB, local network, or SFN. Works without a BSN.Content subscription. Can be uploaded to BSN.Cloud later.

⚠️
Important: A presentation cannot mix BSN Content and Local content. Choose one mode when creating the presentation — changing modes requires starting over.

📐 Canvas Size, Presentation Size & Screen Sizing

🖼️

The relationship between Canvas, Zone, and Output Resolution

Output Resolution = what the player sends to the display (e.g., 1920×1080). Canvas = the total working area of your presentation — usually matches output resolution. Zone = a defined area within the canvas where content plays. You can have multiple zones on one canvas.

Standard Canvas Sizes

1920 × 1080 (Full HD / 1080p)

Most common. Use for standard displays, menu boards, digital signage screens.

3840 × 2160 (4K UHD)

For 4K displays or high-res video. Requires Series 4 or 5 player.

Portrait & Custom Sizes

1080 × 1920

Portrait orientation — rotate the player output in BrightAuthor:connected. Choose Portrait-Bottom Left or Portrait-Bottom Right depending on how the screen is mounted.

Custom (e.g., 3840 × 540 for ultrawide)

For unusual LED wall dimensions. Set the zone size to match your actual pixel count.

Scale to Fit / Fill — What Each Mode Does

Stretch to FillMedia stretched to fill zone exactly. May distort the image.❌ DistortedRarely recommended — only when source resolution exactly matches zone

Sizing Tips for Common Scenarios

🖥️ Standard HD Display (1080p)

Set canvas and output resolution to 1920×1080. Create your media at 1920×1080 for best quality. Use Scale to Fit for mixed content, Fill Screen for background video.

📱 Portrait Screen

Set output to 1920×1080, select Portrait-Bottom Left or Right in presentation settings. Create content at 1080×1920. The player rotates the output automatically.

🖼️ 4K Display

Set canvas to 3840×2160. Requires Series 4 or 5 player. Create media at 4K resolution. H.265 video recommended for best performance at 4K.

💡 LED Wall (Non-Standard)

Set output to a standard resolution equal to or larger than your LED pixel count. Then set the zone size to match your exact LED pixel dimensions. Use a video processor or plugin to scale to the wall. See the LED wall how-to guide.

📺 Multi-Zone Layout

Canvas = full output resolution (e.g., 1920×1080). Create multiple zones that divide the canvas — e.g., main video zone at 1920×900, ticker at 1920×180. Zone pixel values must be set precisely in the zone properties.

🔲 Video Wall (Multiple Players)

Each player drives one screen. Divide the canvas virtually — e.g., for a 2×1 wall at 3840×1080, each player gets a 1920×1080 zone. Use BrightWall plugin or the XC5's built-in multi-screen support.

✅
Best practice: Always create your source media at exactly the resolution of the zone it will play in. This avoids scaling artifacts and gives the sharpest result. For a 1920×1080 zone, export video at 1920×1080. For a 500×200 ticker zone, create graphics at 500×200.

LED Wall — Setting Zone Size for Non-Standard Resolutions

  1. Determine your LED wall's exact pixel dimensions (e.g., 2560×720)
  2. In BrightAuthor:connected → New Presentation → set Output Resolution to a standard resolution larger than your wall (e.g., 3840×1080 for a 2560×720 wall)
  3. In the Layout tab → select your zone → in Zone Properties set Width: 2560, Height: 720
  4. Your content will play at the correct pixel count. The video processor or LED controller handles the physical output mapping.
  5. For Series 5 XC5 players with multiple outputs: use the Screens tab to assign content to each HDMI output independently
  6. For custom resolution via plugin: use a BrightSign modeline plugin to force the player output to a custom resolution directly

🎬 Playlists & Dynamic Playlists

Standard Playlist

A fixed list of media items within a zone. Items play in order then loop. To change content, you must edit the presentation and republish. Content is baked into the presentation file.

Use when: Content rarely changes. Simple loops. No BSN.Content needed for local mode.

Dynamic Playlist ⚡

A cloud-hosted playlist that lives in BSN.Cloud independently of any presentation. Multiple presentations can reference the same dynamic playlist. Update the playlist once — all players using it get the update automatically without republishing the presentation.

Use when: Content changes frequently. One update should reach many screens. Requires BSN.Content.

Creating a Dynamic Playlist — Step by Step

  1. In BrightAuthor:connected → go to Content tab → click New Component → select Dynamic Playlist
  2. Enter a name for the dynamic playlist (e.g., "Daily Specials") → click Create
  3. In the dynamic playlist builder: select a folder in the library on the left → drag media files into the playlist area on the right
  4. Reorder items by dragging them to different positions in the playlist
  5. Select each item to set its properties: Time on Screen (images), Volume (video/audio), and optionally a Validity Date range
  6. Click the Save icon — the dynamic playlist is saved to BSN.Cloud
  7. Now open your presentation → in a zone, instead of dragging media, drag the dynamic playlist widget from the widgets pane
  8. Publish the presentation — from now on, updating the dynamic playlist automatically updates all players using it, no republish needed

Validity Dates on Playlist Items

📅
Validity dates let you schedule when individual items appear inside a dynamic playlist — e.g., a holiday promotion that runs Nov 11–Dec 31. Important: Validity dates use UTC timezone, not local time. Account for the UTC offset when setting start/end times.
  1. Select a media item in your dynamic playlist → check Enable Validity Date in the properties panel
  2. Set Start Date/Time and End Date/Time in UTC
  3. The item shows a clock icon — yellow = not started yet, green = currently active, gray = expired
  4. Save the dynamic playlist — all players update at their next refresh interval

📤 Publishing Content

Publishing a Presentation to Players

  1. In BrightAuthor:connected → open your presentation → click the Publish icon (cloud with up arrow)
  2. Select Players or Groups to publish to. Publishing to a group pushes to all players in that group simultaneously.
  3. Review the publish summary → click Publish to confirm
  4. Content downloads to the player(s) over the network. Players show new content as soon as download is complete.
  5. Check publish status in the Network tab — green = published and playing, yellow = downloading, red = error

Scheduling Content

  1. In BrightAuthor:connected → go to the Schedule tab
  2. Select a Group or player to schedule
  3. Click Add Event → set the day(s) of week and time range
  4. Select which Presentation should play during that time slot
  5. Add multiple events to create a full weekly schedule — e.g., morning content 6am–12pm, afternoon 12pm–6pm, evening 6pm–close
  6. Click Publish Schedule — the schedule downloads to the player alongside the presentations
✅
Dynamic playlist updates don't require republishing. If your presentation contains a dynamic playlist, just update the dynamic playlist content — the player picks up changes at its next refresh interval (configurable, default varies by player).

🔧 Troubleshooting

⬛ Black Screen / No Content

Check in order:
  • → Verify HDMI cable is seated and display input is correct
  • → Check a presentation is actually published to this player
  • → Confirm output resolution in presentation matches display's native resolution
  • → Check player is online in Network tab — may still be downloading
  • → Try rebooting the player from the Network tab → right-click → Reboot

🔴 Player Shows Offline in BSN.Cloud

Check in order:
  • → Check Ethernet cable / WiFi connection on site
  • → Verify network has internet access (not just LAN)
  • → Check that BSN.Cloud ports aren't blocked by firewall (port 443)
  • → Power cycle the player — unplug for 10 seconds
  • → Check if player firmware needs updating

🖼️ Content Looks Stretched or Cropped

Check in order:
  • → Check View Mode setting on the zone — try "Scale to Fit" to preserve aspect ratio
  • → Verify media resolution matches zone dimensions
  • → Check output resolution matches display's native resolution
  • → If using "Stretch to Fill", switch to "Fill Screen and Centered" instead
  • → Re-export media at exact zone pixel dimensions for best results

📋 Dynamic Playlist Not Updating

Check in order:
  • → Confirm you saved the dynamic playlist after making changes
  • → Check player is online — offline players can't receive updates
  • → Check validity dates — items with future start dates won't show yet
  • → Wait for the player's update interval to pass, then check again
  • → Republish the presentation if the dynamic playlist widget was recently added

🎥 Video Stuttering or Not Playing

Check in order:
  • → Check video codec — BrightSign supports H.264 and H.265 MP4. Avoid MOV, AVI, WMV
  • → Check bitrate — keep under 40Mbps for 1080p, under 80Mbps for 4K
  • → Verify SD card / storage speed is sufficient (Class 10 / UHS-1 minimum)
  • → Reduce number of zones playing video simultaneously
  • → Check if player firmware is current — update if behind

❌ Publish Failing or Stuck

Check in order:
  • → Check player is online with internet access
  • → Check player storage isn't full — delete old presentations
  • → Verify BSN.Content subscription is active in Admin tab
  • → Try publishing to a single player instead of a group to isolate issue
  • → Reboot BrightAuthor:connected and retry
